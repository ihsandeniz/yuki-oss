# Opening (acilis-v4) fonts

Subsets used only by the opening seal ("Mühür + Döküm") canvas — runes, planet signs, sun sign.
All three are SIL Open Font License 1.1 (see `OFL-noto.txt`).

| File | Source font | Glyphs |
|---|---|---|
| `run.ttf` | Noto Sans Runic | runic block (unchanged, ~10 KB) |
| `sem.ttf` | Noto Sans Symbols | ☽ ♃ ♄ ☿ ♀ |
| `mat.ttf` | Noto Sans Math | ☉ (+ a few math glyphs) |

Text fonts come from the app's own copies: Fraunces and Martian Mono in
`frontend/assets/fonts/gozlemevi/` (OFL files there). No CDN.
